# Security policy

## Supported version

Security fixes are applied to the latest published release of GMC Radiation Monitor.

## Reporting a vulnerability

Please do not disclose suspected vulnerabilities in a public issue. Use GitHub's private vulnerability reporting feature for the repository when available. Include the affected version, installation type, reproduction steps and any relevant logs with secrets removed.

Do not include MQTT credentials, Home Assistant tokens, GMCMap account identifiers, backup files or measurement databases in public reports.
