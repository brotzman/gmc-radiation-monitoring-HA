# GMC Radiation Monitor 10.0.11

Version 10.0.11 refines the compact application-header controls. The visible language label is removed from above the selector and retained as an accessible screen-reader label. A subtle globe icon is integrated into the selector, which now aligns exactly with the square refresh tile at the same height.

Desktop and mobile layouts keep the language selector and refresh tile in one compact row without horizontal scrolling. Automatic language submission, localized tooltips, keyboard focus, the no-JavaScript fallback and the sticky/floating mobile section navigation are unchanged.

Database schema 8, stored measurements, MQTT entity identities, detector profiles, alarm thresholds, dose conversion, scientific algorithms and serial protocols are unchanged.
