# GMC Radiation Monitor 10.0.14

Version 10.0.14 shortens the German application and browser title from **GMC-Strahlungsüberwachung** to **Strahlungsüberwachung**. The subtitle **Lokale Überwachung für GQ-GMC-Geigerzähler** remains unchanged.

This is a presentation-only change intended to reduce the header width on desktop and mobile devices. Other interface languages, the compact view/language/status controls, the sticky mobile navigation, database schema 8, stored measurements, MQTT entity identities, detector profiles, alarm thresholds, dose conversion, scientific algorithms and serial protocols are unchanged.
