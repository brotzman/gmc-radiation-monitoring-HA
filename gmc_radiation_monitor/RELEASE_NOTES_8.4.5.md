# GMC Radiation Monitor 8.4.5

Version 8.4.5 focuses on visual hierarchy and progressive disclosure.

- The current dose rate is now the primary live value, with CPM, active detector and quality directly beneath it.
- Technical device metadata is limited to Expert view.
- Detector tubes are presented as compact visual cards in Analysis and Expert views.
- Raw/corrected CPM, dead-time loss and correction factor are grouped in a collapsed Expert section.
- Calibration and load colours remain consistent: green normal, yellow attention/working values, orange correction, red restricted or incomplete.
- Measurement-quality stars retain an explanatory tooltip and are no longer duplicated as a large tile.
