# GMC Radiation Monitor 9.0.3

Version 9.0.3 is a focused interface-consolidation and localisation release for the 9.0 architecture.

## Improved

- Replaces the permanently visible six-tile system overview with one compact status line.
- Keeps connection state, latest accepted value and storage state visible at a glance.
- Moves exact storage time, rejected peaks, stored-value count and database size into collapsible details.
- Automatically emphasizes warnings and errors while keeping normal operation visually quiet.
- Uses German decimal commas and thousands separators consistently in the German dashboard.
- Applies the selected UI locale to browser-updated report previews, backup previews, durations, sizes and counts.
- Keeps version numbers, device model identifiers, serial numbers and machine-readable values unchanged.

## Continued 9.0 capabilities

- Retains independent measurement freshness, report presets and copy-safe support-diagnostics introduced in 9.0.2.
- Keeps database schema 8 and all existing data fully compatible.

## Compatibility

- Keeps database schema 8 and existing history fully compatible.
- Does not change serial acquisition, detector profiles, calibration, CPM acceptance, dose conversion, statistical calculations or report metrology.
